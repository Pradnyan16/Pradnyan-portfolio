# Pradnyan's Portfolio

A minimalist, high-performance developer portfolio built to showcase engineering work, design capabilities, and technical projects.

## Tech Stack
- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Content:** MDX / Gray Matter
- **Deployment:** [Vercel](https://vercel.com)

## Features
- 🌗 **Dark/Light Mode:** Seamless theme switching with `next-themes`.
- ⚡ **Performance:** Statically generated and optimized for maximum speed and Lighthouse scores.
- 🎨 **Minimalist Design:** Focuses on typography, whitespace, and smooth micro-interactions.
- 📱 **Responsive:** Carefully crafted to look perfect on mobile, tablet, and desktop.

## Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Pradnyan16/Pradnyan-portfolio.git
   cd Pradnyan-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open [https://pradnyan.xyz](https://pradnyan.xyz) in your browser.

## Customization
To customize this portfolio for your own use:
1. Update `src/app/page.tsx` with your personal information.
2. Modify the `src/components/About.tsx` file to reflect your background.
3. Replace the projects data with your own work.
4. Update the contact form details in `src/components/MessageForm.tsx`.
